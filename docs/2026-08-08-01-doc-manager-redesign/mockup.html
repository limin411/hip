文档管理 就绪

标注模式 改造点速览 点击卡片定位对应区域

1
导航行改名：知识库 → 文档管理侧边栏导航行（图标 + 名称）由 BookOpen「知识库」改为 FolderTree「文档管理」，徽标计数 = 顶层条目数；激活态沿用灰底（bg-state-active）。旧版：知识库（BookOpen），计数 = 空间数
2
侧边栏 = 单层级目录（像电脑文件夹）每次只显示当前层级的文件夹与文档：点文件夹进入，↑ / 面包屑 / Alt+← 返回上一层。不再渲染递归整树，20 层深度一样流畅。旧版：仅列出「空间」，需进入主页面才能看到树
3
分区头：当前目录 + ↑ + 新建列表头由「知识空间」改为「当前目录」；右侧为 ↑ 返回上一层（根目录置灰）与「+ 新建」下拉：文件夹 / 文档 / 画板，在当前层级就地命名。旧版：知识空间 + 新建知识库（空间级对话框）
4
↑ 返回上一层 + 面包屑文件管理器式向上导航；点击面包屑任意层级直接跳回；根目录时按钮置灰。快捷键 Alt+←。旧版：只有树内面包屑，无向上入口
5
浏览模式（新增）文件夹内容以「文件夹网格 + 文档列表」展示，支持网格/列表切换、排序（文件夹优先）。点击文档进入阅读/编辑。旧版：打开空间后固定左树右文，无内容概览
6
深目录：20 层体验面包屑超 3 段折叠为「…」，点击弹出祖先跳转菜单直达任意层级；hover 显示完整路径。可试试点开「深度目录（20 层演示）」，再用「…」跳回根。旧版：整树递归展开，深层目录难用
