设计说明 — P0/P1/P2 速览 · 快捷键 · 与真实实现的差异

P0 Diff 可见性（核心）

  • T1 变更行 7% → 13% 底色 + 2px 色条 rail，hover 加深
  • T2 连续变更成「块」：圆角 + 连续内描边，块间留隙
  • T3 行号列加分隔/底纹，add/del 行号随行变色
  • T4 word diff 强度提升，并排视图补齐行内高亮
  • T5 hunk 头新增 +N −M 量化徽标
  • T6 上下文行数档位（全部 / 5 行 / 2 行）

P1 面板体验

  • T7 顶部 sticky 汇总条：文件数 + 总增删 + 折叠/展开/刷新
  • T8 ⌘F 文件筛选，Esc 还原，无匹配空态
  • T9 刷新进行中 spinner 反馈
  • T10 ⌥⌘↑↓ hunk 键盘导航 + 目标高亮淡出
  • T11 上下文展开/收起（复用 sidecar context 参数）
  • T12 变更行 hover 行级操作：复制行 / 引用到对话
  • T13 文件级 / 全局「复制 diff」（git diff 文本）

P2 语义与无障碍

  • T14 审查三级粒度：全部 / 单文件 / 单 hunk「解释此改动」
  • T15 色盲安全（+/− 符号、字母 chip）+ aria 行语义
  • T16 长文件 diff minimap（>400 行可选）
  • T17 文件按状态分组排序（A/M/D/R）

与实现差异：本预览的变更块用「外层 wrapper 描边」近似实现，落地时为每行 inset box-shadow 组合（不挤占内容宽度）；上下文展开在本预览中为单键整体切换，落地时拆为「展开 ↑N / ↓N」两侧按钮；为便于演示，预览默认开启「5 行」紧凑上下文，落地默认保持现状「全部」（T6 为可选档位）；其余交互（筛选、汇总条、hunk 导航、行级操作、审查注入、toast）与 spec 一致。方案细节见 docs/design/changes-diff-stage/changes-diff-clarity-spec.md。
