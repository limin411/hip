v2 关键改动（对照 v1）

  • 提交区默认收起 36px，有改动时未提交区优先
  • 仅展开行吸顶，多开时按顺序堆叠（⌘/Ctrl+Click 多开试试）
  • 丢弃 = 副本入回收站 + 恢复到 HEAD（Popover 确认）
  • hunk 头部 hover 浮出：复制 / 标注给 agent / 引用到输入框
  • 「审查」注入 composer，结构化报告回对话
  • ⋯ 菜单：统一/并排 · 忽略空白 · 全部折叠/展开 · 刷新

交互演示

  • 点击行展开/收起；⌘/Ctrl+Click 多开文件
  • hover 行尾：↺ 丢弃（弹确认）· ↗ 打开 · ⋯
  • hover hunk 头部右侧浮出操作按钮
  • 点击提交行查看该 commit diff，点「← 未提交」返回
  • 拖拽分隔条调整提交区高度
  • 切换 宽/中/窄 演示窄栏压缩；勾选「无会话起点」看基线禁用态
  • 键盘：j/k 移动 · space 展开 · ⌘/Ctrl+Enter 审查 · Esc 关闭/返回 · ? 提示
