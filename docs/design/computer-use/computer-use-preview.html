Compute Use（电脑操控）

通用设置 · 方案总览 · 仅承诺 macOS / Windows
决策 1双感知模式

模型不一定有多模态能力：vision（截图坐标）与 accessibility（AX/UIA 文本树 + element_id）双路径，auto 自动降级。

决策 2原生执行通道

截图/输入注入放 Rust（xcap + enigo），sidecar 经 UI 桥触发 —— 复用 terminal_exec 桥接模式，macOS TCC 权限绑定 app 本体。

决策 3安全基线

锁屏拒绝执行；输入动作 HITL 审批；截图不落盘不进 DB；执行期徽标 + Esc 中断。

决策 4平台承诺

v1 仅 macOS + Windows；其他平台设置页显示「暂不支持」，工具不注入。

04HITL 审批弹窗（原型）

复用现有 PermissionRequestPayload 渲染，新增 kind:'input'；点击动作卡片模拟一次审批流。

input · computerleft_click需审批
该动作将注入真实鼠标/键盘事件；如触发 screenshot，当前屏幕内容将发送给模型（仅内存往返，不落盘）。

05动作 × 审批矩阵 · 工具注入门控

只读动作永不审批；askOnce 按回合记忆（同 isApproved 机制）；maxStepsPerTurn 为硬上限。

门控工具注入条件

resolveComputeUseMode(...).available = 配置开启 ∧ 平台 macOS/Windows ∧ 权限就绪 ∧ 模式可解析 —— 任一不满足则 computer 工具不注册。

防线三道兜底

① 锁屏拒绝（locked 错误码）；② 回合步数上限；③ Esc 中断（AbortController 透传，同 stop 语义）。

隐私数据边界

截图仅内存往返：不进 sessions DB、不进附件表；历史回放显示「[截图] computer screenshot 1200×800」占位文本。
