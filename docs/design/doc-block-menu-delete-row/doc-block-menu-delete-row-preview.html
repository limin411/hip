§3 子菜单「颜色」

布局未坏（已用 icon prop）。要判断的是：维持 20 行列表，还是 升级为 swatch 色板。

P1 现状/皮肤 长列表

BlockNote ColorPicker：文字 10 + 背景 10。
布局 OK · 密度差：一屏扫不完，是线性阅读而非空间选色。
P1 只统一行高 / Label 次级色，不改结构。

P2 目标 Swatch 色板

两段 label + 5×2 圆点（文字）/ 方点（背景）。当前色外环。
点击可连选试色，菜单保持打开；Esc / 外点关闭。
建议另 PR，不堵删除与 Turn-into。

议题选项决定
删除怎么修 span flex 热修 / 走 icon 槽 / 加宽菜单 走 icon 槽 + CSS nowrap。热修不对齐。

§7 验收清单

  • P0 删除单行；图标与主菜单共线；danger hover 淡红底

  • P1 转换成父行有 icon+▸；子项 leftSection glyph；当前类型 ✓
  • P1 子菜单右展 / 贴边 flip / Esc 分层关
  • P1 颜色父行 icon；列表 Label 次级色；选色仍生效
  • P2 颜色 swatch 网格 + 当前环 + 键盘（可选本迭代）
  • 亮色 / 暗色均通过
