文档管理浏览视图交互整改

doc-browse-interaction · 对齐 Notion All pages · 对照 spec §3
S8选择与打开分离

选区态单击 = 切换选中（永不打开）；打开只由双击 / Enter / 非选区态单击触发。

S9入口恒可见

行 hover 出现六点手柄（点按 = 选中，拖动 = 拖拽）+ 行尾 ⋯；选区态行首变复选框。

S10全类型统一

文件夹 / 文档 / 表格一律可多选；Shift 连选按可见行序（含文件夹），规则不再分裂。

S11–12新建置顶 · 批量条置顶

内联新建行出现在列表首位；批量条改为工具栏下通栏上下文条，不再底部悬浮遮挡。

S13列头排序

名称 / 最后编辑列头 + Sort 菜单（视图态排序）；拖拽行时自动退出排序。

现状：已有多选时普通单击 = 先清空全部选择、再打开文档——一次点击做两件相反的事，误触即丢选择；且文件夹不能多选、Shift 连选跳过文件夹造成选区与视觉错位。
