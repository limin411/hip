01

现状诊断：四个问题

来自全库扫描（src/ 135 个文件、lucide-react 引用统计）

① 风格漂移

strokeWidth 混用 1.5 / 1.6 / 1.75 / 2 / 2.5 五种；尺寸混用 14 / 16 / 18 / 20 / 24 五档。同一界面内粗细不齐，视觉噪点明显。

1.75 × 143 处 2.0 × 10 处 1.5 × 3 处

② 语义含混

「会话」用 MessageSquare 单气泡、「任务」用 CheckSquare 方框勾 —— 形状雷同、信息量低；「知识库」用 FolderTree 文件夹树，与「项目」的文件夹意象打架。

MessageSquare ×4 Zap 双重含义 Folder 家族 ×4

③ 品牌缺失

六大导航图标与 VS Code / Linear / 任意 Electron 应用无差异 —— 打开应用先看到的不是「hip」，而是「通用图标包」。空状态、欢迎页同样缺乏品牌触点。

0 个自绘图标无品牌符号

④ 状态表达单一

导航选中态只有灰底（bg-active），图标不参与状态表达；禁用态、hover 态无图标级区分。颜色语义（accent 橙）没有进入图标层。

active = 灰底无图标色
02

升级原则

与 DESIGN.md 五原则一一对应，不引入新风格

直角优先

品牌图标描边端点/连接用 square（直角），与产品「Sharp over Round」一致，形成与 Lucide 圆头描边的差异层级：圆头=通用，直角=品牌。

单色为主，一色强调

图标默认中性灰继承文字色；仅导航选中态用 accent 橙。禁止渐变、发光、多彩填充。角色色只保留给 agent 角色指示点。

语义即形状

每个功能图标携带一个「记忆点」：会话=双气泡、自动化=循环+闪电、知识库=书+星标。形状本身可被 16px 小尺寸辨认。

零新增依赖

品牌图标为内联 SVG React 组件，兼容 LucideIcon 类型签名；通用图标继续用 lucide-react。无网络字体、无图标字体、无第三方库。

图标状态规范

四个状态，一套规则 —— 只用底色 + 图标色，无位移无缩放
Default color: text-secondary
描边 1.75 · 无底
Hover 底 bg-state-hover
color: text-primary（100ms）
Active 底 bg-state-active
图标 accent-strong · 计数 chip 反白
Disabled opacity: 0.38
pointer-events: none
动效纪律：图标本身永不位移/缩放/旋转；只允许 background-color 与 color 过渡（≤100ms）。 与 DESIGN.md「克制动画 Fade-only Motion」一致。加载态用 Loader2 旋转（既有保留项，旋转是其语义本身）。
