双向IM ⇄ hip 对话

IM 发消息 → 智能体执行 → 自动回复。三平台官方长连接，本机免公网 IP、免回调加解密。

HITL卡片确认

需要授权时 IM 收交互卡片：允许一次 / 总是允许 / 拒绝，点按钮即生效，桌面端同步清除。

安全默认最严

授权名单默认空 = 无人可对话；未授权进「待授权」；权限模式默认 confirm（全部走卡片确认）。

网关在 sidecar

凭证存 im-connectors.json（0600）；hip 退出即 IM 离线；Rust 零改动。
