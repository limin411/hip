新建表格（Table）· 高保真交互原型

文档管理域 · docs/design/knowledge-table · 配套 spec
决策 1轻表格定位

Notion 简易表格的轻量 + 飞书字段类型子集；不引入"数据库/视图"心智，保留 P2 升级位（Turn into database）。

决策 2入口三处一致

新建下拉 / 右键菜单 / 空文件夹空态，均与「新建文档」同构：内联命名 → Enter 创建并打开。

决策 3列 = 类型化字段

文本 / 数字 / 勾选 / 日期 / 单选 5 种起步；双击列名即改类型（飞书"类型第一性"，收敛为列菜单一项）。

决策 4键盘优先 + CSV 文件

Tab/Enter/Esc 全键盘导航（Sheets 肌肉记忆）；存储 tbl_*.csv + meta.json，AI 智能体可直接读写。

操作提示：场景一可点「新建」下拉、右键列表空白处、双击「归档（空）」看空态；场景二可双击单元格、点表头菜单、拖拽行手柄/列头/列宽、开筛选与统计，⌘Z / Ctrl+Z 撤销。
