> 版本：v3.0（2026-08）
> 范围：**文档内细节体验与视觉样式**（区别于 V2 的编辑模型/功能补齐）。V2 已解决"有没有"（分栏/块引用/反链/⌘K/无源码模式），本版解决"像不像"——打开文档后的每一个交互细节与视觉呈现向 Notion 对齐。
> 配套文件：

> 前置基线：`docs/2026-08-08-02-doc-manager-vs-notion/spec.md`（V2.1 功能决策，本版继承其范围决策）；`DESIGN.md`（全局 Flat Solid 设计语言，本版提出**文档域子语言**特例并列出冲突裁决）。

## 1. 根因分析：为什么差距大

### 1.1 直接原因（代码审计结论）

打开文档后，用户看到的是四层结构，每层都与 Notion 相悖：

| 层级 | hip 现状（代码出处） | 与 Notion 的差距 |
|---|---|---|
| **① 顶部工具栏** | `KnowledgeWorkspace.tsx`：48px 高常驻横条 = 路径面包屑 + 保存状态圆点文字（"已保存/保存中"）+ ⋯ 菜单 | Notion 桌面端无此条：无面包屑、无常驻保存提示（自动保存无感，仅底部状态栏极短暂提示）；文档顶部只有页面标题 |
| **② 标题区** | `InlineDocTitle.tsx`：28px / 600 / `-0.02em`（`text-page` token），输入框紧贴正文 | Notion 页面标题 40px / 600，标题与正文间有约 24px 留白；空文档标题下方有斜体占位 "Type '/' for commands"；标题 hover 出现页面级 ⋯ 菜单 |
| **③ 正文排版** | `knowledge-doc-typography.css`：body 15px / line-height **1.7** / 块间距 0.2rem、段距 0.35em；h1 1.75em(≈26px)、h2 1.375em(≈21px)、h3 1.15em(≈17px)；文字 `#111` 纯黑；页宽 46rem(736px) | Notion：body 16px / **1.5** / 块距与段距均 4px（更紧凑）；h1 30px / h2 24px / h3 20px；文字暖黑 `#37352f`；页宽 708px。hip 当前是"文章/博客"节奏，Notion 是"块笔记"节奏 |
| **④ 块级细节** | `knowledge-blocknote.css` + `DocBlockNoteEditor.tsx` | 见 §1.2 逐项 |

### 1.2 块级细节差距逐项（审计对照）

| # | 细节 | hip 现状 | Notion 参照 | 差距等级 |
|---|---|---|---|---|
| D1 | 行首手柄 | 4 个按钮（＋/多选/拖拽/块链接），`min-width:2rem` 整组淡入 | 单个"⋮⋮"六点手柄（2×3 点阵，2px/点），hover 该行才显示；行首另有单个 ＋ | 大 |
| D2 | 待办 checkbox | 原生 `<input type=checkbox>` + `accent-color` 橙色，1rem 方块 | 自绘 16px 方块：1.2px 边框圆角 3px；勾选后深灰填充白勾 + **文字删除线变灰** | 大 |
| D3 | 引用块 | 3px 左边框 + **文字降灰**（`text-secondary`） | 3px 边框（暖黑）+ **文字保持正文色** | 中 |
| D4 | 代码块 | 默认深色底 `#0d1117`（GitHub dark 风）+ 1px 边框 | 浅色主题下浅灰纸面 `#f7f6f3`、无边框、右上角语言徽标 | 大（反差最强） |
| D5 | 表格行 hover | `accent 6%` 橙色 tint + 表头灰底 | 中性暖灰 `#f7f6f3` 行 hover，表头浅灰 | 中 |
| D6 | 气泡工具栏 | BlockNote 默认：块类型选择 + B/I/U/删除线/行内码/链接/颜色 | 精简 B/I/U/S + 链接 + 更多；8px 圆角、柔和阴影 | 中 |
| D7 | 斜杠菜单 | 自研 `BlockNoteHipSlashMenu`：宽 18rem(288px)、图标+文字行 | 356px 宽、46px 图标列、分组标题 12px 大写灰字、项高 40px | 中 |
| D8 | 选区高亮 | `--kb-selection` = accent 22% 橙 | 蓝色系（`#b3d7ff` 类） | 小 |
| D9 | 保存状态 | 顶部常驻"圆点+文字"（`knowledge-save-status`） | 无感自动保存；底部状态栏仅极短暂 "All changes saved" | 大 |
| D10 | 页面级菜单 | 顶部 ⋯（版本/导出/模板） | 标题行 hover 的 ⋯；顶部无常驻按钮 | 中 |

### 1.3 深层原因（为什么"越改越不像"）

1. **设计语言同源冲突**：`DESIGN.md` 把 hip 定位为"Flat Solid / Linear / Vercel / GitHub Desktop 气质"，工具壳极强：13px 基准字号、1px 边框、橙色强调、锐角。Notion 是"纸张隐喻"：暖黑正文、低对比灰边框、柔和阴影、大留白、16px 阅读字号。文档区目前**完整继承了工具壳语言**（顶部工具栏就是典型），所以"打开文档=打开一个文件管理器"，而 Notion 是"打开一张纸"。
2. **BlockNote 默认交互未被二次设计**：侧边菜单、气泡工具栏、checkbox 都是框架默认形态，CSS 只做了"去 Mantine 化"的表面补丁（扁平化），没有把交互形态（手柄样式、hover 时机、多选手势）重做成 Notion 形态。
3. **文章排版参数继承了"阅读器"心智**：15px/1.7/大段距来自旧 `DocReader`/Typora 阅读体验，与 Notion 的紧凑块编辑节奏不一致；标题层级整体小一档。
4. **文件管理器心智残留**：面包屑、↑ 返回、保存状态、浏览视图的"图标网格+表格"——这些是 Finder/语雀心智，与 V2 spec 自己声明的参照系（Notion/飞书）矛盾。

### 1.4 结论

差距不是功能缺失（V2 已补齐功能），而是**文档域缺少一套独立的"纸张"子语言**，以及**若干块级交互仍是框架默认**。整改 = 在 hip 全局 Flat Solid 不变的前提下，为文档域建立 Notion 风格子语言（§3），并逐项替换块级交互（§4）。

## 2. 目标与设计原则（文档域子语言）

### 2.1 一句话目标

> 打开文档时，用户看到的是"一张纸"（Notion），而不是"一个文件列表"（Finder）。chrome（侧边栏/⌘K/设置）保持 Flat Solid 不动。

### 2.2 子语言五原则（与 DESIGN.md 的冲突裁决）

| 原则 | 内容 | 与 DESIGN.md 冲突 | 裁决 |
|---|---|---|---|
| S1 纸张底与暖文字 | 文档区底色 = 现有 `bg-surface-content`（白/暗），正文用**暖黑**（亮 `#2f2c28`，暗 `#e8e6e1`）；chrome 灰阶不变 | 色块优先原则不禁止暖灰阶（中性灰仍占主体） | 不冲突，新增 `--kb-text` 系列 token |
| S2 内容优先 | 文档顶部无常驻工具栏：面包屑降为标题上方 12px 小字路径（hover 才显底色）；保存状态移出或极淡化 | 边界优先原则不要求"必有边框条" | 不冲突 |
| S3 紧凑块节奏 | body 16px / 1.5；块距、段距统一 4px；h1 30px / h2 24px / h3 20px；默认页宽 708px（`--kb-measure` 调整） | 与"克制"精神一致 | 不冲突，改 `knowledge-doc-typography.css` 变量 |
| S4 柔和局部 | 文档域浮层（气泡/斜杠/手柄菜单）允许 8px 圆角 + `shadow-overlay`；禁用渐变/玻璃（同全局） | 与"直角优先"部分冲突 | **文档域特例**：仅浮层与 checkbox 允许 6–8px 圆角，正文块 0；其余 chrome 不动 |
| S5 中性 hover | 文档内 hover/选中一律**中性暖灰**（亮 `#f0efec`、暗 `#2f2f2f`），不出现橙色 tint（选区/表格行/菜单项/手柄） | 与橙色强调色冲突 | **文档域特例**：橙色仅保留给"操作意图"（按钮实底/激活态），文档内容 hover 全灰 |

> 评审点：S4/S5 是仅有的两处全局原则特例，需在代码中以 `knowledge-doc-paper` 作用域隔离，不得泄漏到 chrome。

## 3. 整改项清单（文件级）

### P0 — 文档页视觉与交互（核心，1–2 周）

**T1 顶部工具栏瘦身**（`KnowledgeWorkspace.tsx`）
- 现状：`h-12` 常驻条：面包屑 + 保存状态 + ⋯ 菜单。
- 改法：
  1. 删除常驻条；面包屑改为文档标题**上方一行 12px 小字路径**（`pathNodes` 复用），左对齐于正文列（`knowledge-doc-inline-pad`），hover 项才显灰底；
  2. ⋯ 页面菜单移入标题行：标题 hover 时标题左侧出现 ⋯（对齐 Notion），菜单内容不变（版本/导出/模板）；
  3. 保存状态：移除顶部常驻；改为**底部状态栏**左侧 12px 灰字（对齐 Notion 桌面端 "All changes saved" 位置），仅在 `saving/error` 时显示（`saved` 静默），error 时显示重试按钮。
- 验收：文档打开后顶部无 48px 条；标题行 hover 出现 ⋯；连续编辑 10s 无任何"已保存"提示出现；`knowledge-save-status` testid 仅存在于状态栏。

**T2 标题区对齐**（`InlineDocTitle.tsx` + `PageHeader.tsx`）
- 现状：28px / 600；输入框 `pb-2 pt-1.5`。
- 改法：`text-page` 改 32px（桌面感知平衡，40px 在工具窗口内过重；**32px 为本域裁决值**，理由：窗口宽度 ~1200px 场景下 40px 标题占屏比过高，Notion 桌面宽窗口才用 40px）；`font-semibold` 保持 600；标题下留白 `pb-4`（16px）；空文档时标题下方渲染斜体灰占位 "输入 / 或输入文字开始"（对齐 "Type '/' for commands"），首次输入即消失。
- 验收：新文档打开 = 标题 + 斜体占位；输入首字符占位消失；截图对比 Notion 间距比例一致。

**T3 正文排版参数**（`knowledge-doc-typography.css`）
- 改法：`--kb-font-body: 16px`；`--kb-line-body: 1.5`；`--kb-para-gap: 4px`（`0.25rem`）；`--kb-block-gap: 4px`；`--kb-h1-size: 30px`、`--kb-h2-size: 24px`、`--kb-h3-size: 20px`（固定 px，不再 em 相对）；标题 margin 收敛为 `0.9em 0 0.3em`；`--kb-measure` 默认 `min(100%, 44.25rem)`（708px，对齐 Notion），wide/full 设置项保留。
- 影响面：`knowledge-doc-prose`（阅读/导出）同步继承，导出 HTML 视觉随之变化（可接受，README 无截图承诺）。
- 验收：对照 D3 检查正文节奏；单测无（纯 CSS），用预览页对比。

**T4 行首手柄 Notion 化**（`DocBlockNoteEditor.tsx` `KnowledgeSideMenu` + CSS）
- 现状：4 按钮组 `min-width:2rem`。
- 改法：hover 行时左侧显示**单个六点手柄**（`⋮⋮`，2×3 圆点阵，SVG 内联 24×12）；点击手柄 = 块菜单（复制/块链接/删除/拖拽排序）；行首另保留 ＋（AddBlockButton）在 hover 时显示；多选改为"点击手柄 Shift+拖拽"（P2 完成前保留 shift+点击逻辑，入口藏入手柄菜单）。
- 验收：单行 hover 只出现手柄+＋；手柄菜单项与 Notion 菜单项一一对应；e2e 选择器更新（`kb-side-menu` → 手柄）。

**T5 待办 checkbox 自绘**（`knowledge-blocknote.css` + 待办块渲染）
- 改法：隐藏原生 input，CSS 绘制 16px 方块（边框 1.2px 暖黑、圆角 3px）；勾选态 = 深灰填充 + 白勾 SVG + 文字删除线 + 暖灰文字色；行内码不受影响。
- 验收：勾选切换有 120ms 过渡；键盘操作（空格）可用；e2e 回归 `mdTasks` 相关。

**T6 引用/分割线/表格细节**（CSS）
- 引用：边框色 = 当前文字色（`currentColor`，3px），**文字不再降灰**；
- 表格：行 hover 改中性暖灰（S5）；表头灰底保留；第一列不加粗；
- 分割线：`#e8e8e8` → 用 `--border` 已有值即可，保持。

**T7 气泡工具栏精简**（`DocBlockNoteEditor.tsx` FormattingToolbar 组装）
- 现状：块类型 + B/I/U/删除线/行内码/链接/颜色。
- 改法：**B/I/U/S + 链接 + 颜色**（删除块类型选择、删除线、行内码——Notion 在第二级菜单）；8px 圆角、柔和阴影；选中态 = 暖灰底（S5）。
- 验收：选区弹出工具栏 6 个按钮；无块类型下拉。

**T8 斜杠菜单尺寸与分组**（`BlockNoteHipSlashMenu.tsx`）
- 改法：宽 356px（`w-[22.25rem]`）；图标列固定 46px（图标居中于 30px 圆角块）；分组标题 12px/大写/灰字、`px-3 pt-2.5 pb-1`；项高 40px；选中项暖灰底 + 右侧箭头淡显。
- 验收：与 Notion 菜单截图尺寸比例一致；键盘导航回归。

**T9 选区与 hover 中性化**（CSS）
- 改法：`--kb-selection` 改为中性蓝灰系（亮 `rgba(45,110,220,.18)`）；代码块内选区不变（深色底）。
- 验收：正文选区不再是橙色。

### P1 — 管理视图与侧边栏细节（1 周）

**T10 浏览视图列表行 Notion 化**（`DocManagerBrowse.tsx`）
- 现状：网格 tile（56px 图标卡 + 标题 + 日期）+ 表格（名称/类型/修改时间）。
- 改法：
  1. **列表为默认视图**：行高 40px；行 = 类型图标（文档 20px 圆角纸面图标/文件夹）+ 标题 + 右侧"上次编辑"12px 灰字 + hover 显示行尾 ⋯ 菜单（右键菜单同 payload）；行 hover 整行暖灰；
  2. 网格保留但 tile 缩为 40px 图标 + 标题两行，hover 显示右上 ⋯；
  3. 工具栏瘦身：去掉"↑ 返回 + 视图切换"常驻——面包屑行保留（小字）、视图切换移入 ⌘K 或右键；保存 `view` 偏好到配置。
- 验收：默认打开 = 紧凑列表；行 hover 出现 ⋯；网格切换仍可用。

**T11 侧边栏目录行 hover 操作**（`DirNavList.tsx`）
- 现状：行 hover 仅底色；新建/重命名/删除都在右键菜单。
- 改法：行 hover 时右侧出现"＋"（新建子项）与"⋯"（菜单，payload 复用右键）；选中态从"橙色左条+accent/10 底"改为**整行暖灰底 + 左条保留但改中性深灰**（S5 特例扩展到侧边栏文档区；chrome 其他区域不动）。
- 验收：hover 行出现两个操作按钮；选中行视觉与 Notion 侧栏一致。

**T12 空态与首次引导**
- 浏览空文件夹：大标题（24px）+ 灰字说明 + 主按钮"新建文档"（Notion 风格空态），替换现有 12px 灰字 + 文字按钮。
- 新文档首次打开：标题占位 + 斜体 "/" 提示（T2 已含）。

### P2 — 交互补齐（按需，2–4 周）

- **T13 手柄拖拽多选/排序**：点击手柄拖拽 = 连续多选（Notion 手势）；块拖拽排序动画（ProseMirror 原生支持，补 CSS 拖影）。
- **T14 页面图标（emoji）**：标题左侧 emoji 图标 + 随机兜底。⚠️ 与 v2.1"文档不承载元数据"决策冲突，需产品重新裁决；若不通过则跳过。
- **T15 块菜单重构**：手柄菜单 = 复制块链接/复制/删除/多选/拖拽（对齐 Notion 块菜单结构）。

- 全局设计语言改造（Flat Solid 保留，仅文档域特例 S4/S5）；

## 6. 风险与对策

| 风险 | 等级 | 对策 |
