1. 本次增量决策

相对上一版「精简 TitleBar + 浮窗右栏」，进一步对齐 IDE / Agent 工作台的「整窗三栏」。

取消 · 顶部标题栏

  • 不再保留全宽 TitleBar 行
  • 不再在顶栏放会话标签 / 返回条
  • 窗口拖拽与红绿灯让位下沉到左侧边栏顶部
  • 当前会话标题改到主列局部工具条（可选，非窗口 chrome）

改为 · 右侧正常抽屉

  • 去掉 p-3 内边距浮层壳
  • 去掉 rounded-xl + shadow-panel
  • 贴窗右缘、顶底拉满，仅 border-left 分隔
  • 宽度仍由 Panel 拖拽调节；收起 width→0
可以，且建议一起做： 无顶栏后垂直空间全部给三栏；右栏若仍用浮窗会在「全高侧栏」旁边显得漂浮、留白浪费。抽屉与左栏对称，视觉更稳。

3. 取消顶栏后的系统 chrome 落点

hip 是 Tauri 桌面端；去掉自定义 TitleBar 不等于忽略窗口控件。

平台做法实现提示
macOS Overlay 红绿灯压在左上侧栏；侧栏顶部 --lights-inset 空白 + drag region 保留 data-tauri-drag-region 在侧栏顶；内容勿压绿灯
Windows / Linux 继续用系统标题栏（OS decorations），应用内容从系统栏下方开始 与现 CSS data-platform 一致：无玻璃、无 90px 让位
拖拽移动窗口 侧栏顶条 +（可选）主列 toolbar 空白区可 drag 按钮/列表 data-no-drag
原 TitleBar 功能迁移 ⌘K、连接状态、面板开关 → 主列 toolbar 右侧；返回设置/历史 → 侧栏底部或主列 不再需要 specialView 顶栏返回模式的独立 chrome 行

4. 右侧：浮窗 → 抽屉

状态机不变（codePanelOpen / chatPanelOpen + resizable Panel），只改视觉与盒模型。

浮窗（现状）抽屉（目标）
外层 p-3 四周 gutter 无 gutter，贴边
卡片 rounded-xl border shadow-panel 直角（或仅内侧细分割），无阴影
高度 窗口高 − 2×padding − 顶栏 与侧栏/主区同高 100%
打开动画 animate-panel-in 卡片入场 宽度 0 → N%（Panel expand），可选 content fade
分割线 弱化 grip 浮在 gutter 全高 border-left + 中部 grip
代码落点 AppLayout 内 right-panel-float 直接渲染 ArtifactPanel / PreviewPanel 填满 Panel
实现几乎只改 AppLayout 壳： 删除 float wrapper；Panel 内 h-full border-l bg-surface-subtle 即可。 PanelToggle 语义保留，只是从 TitleBar 挪到主列 toolbar。
