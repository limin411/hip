## 1. 根因分析：用户为什么觉得「怪」

表格功能（PR-3..6）已完整落地：5 种列类型、键盘导航、排序/筛选/统计、撤销重做、CSV 导出。但**交互层仍是"代码写出来了"的状态，不是"人用着顺"的状态**。按用户感知可归为三类，逐一对应代码证据：

### 1.1 键盘"时灵时不灵"（最致命的怪）

| # | 现象 | 代码证据 | 根因 |
|---|---|---|---|
| K1 | 鼠标点完单元格，再按方向键/Enter **完全无响应**（或滚动页面） | `TableEditor.tsx` 全文无任何 `focus()` 调用；td 仅 `tabIndex={-1}`，单击只 `setSel` 不聚焦 | 网格键盘处理挂在 `<table tabIndex={0}>` 上（L937-938），但鼠标交互从不把焦点移回表格。键盘导航只在用户恰好 Tab 到表格元素时才生效——不可发现、不可依赖 |
| K2 | 编辑单元格按 Enter/Tab 提交后，焦点同样丢失（input 卸载 → focus 回 body），继续打字/方向键失灵 | `commitEdit()`（L147-155）只 `setEditing(null)` + `setSel`，无焦点归还 | 同上 |
| K3 | 编辑态按 Tab 从**最后一列**提交后，选择位置越界（`setSel({ri, ci: ci+1})`，L1003），选中框消失，后续方向键跳变 | 编辑输入 `onKeyDown` 的 Tab 分支直接 `ci + 1` 不取模 | 编辑态与网格态两套 Tab 逻辑不一致（网格态会换行/加行，编辑态不会） |
| K4 | 编辑态按 Enter 提交后**不向下移动**（Notion/Sheets 是提交并下移），要再按一次 Enter 才动 | `commitEdit()` 固定 `setSel({ri, ci})` | 编辑态无"提交后移动"语义 |
| K5 | 单元格内无法换行：Shift+Enter 只是往 `value` 里塞 `\n`，但渲染是单行 `<input>`（L1287），换行内容看不到也编不了 | 编辑态用 `<input>` 而非 `<textarea>` | 文本列承诺"可换行"（原 spec §3.3.2），实现缺失 |
| K6 | **没有复制/粘贴**：⌘C/⌘V 无任何处理（`handleGridKeyDown` 只处理 ⌘Z/⇧⌘Z），从 Excel/网页表格/Notion 复制内容无法粘入，表内多格也无法复制 | 全文无 `navigator.clipboard` / `copy` / `paste` | 表格最基础的数据迁移通道缺失 |
| K7 | 没有选区概念：⌘A / Shift+方向键 / Shift+点击 全部无效，Delete 只能清单格 | 选择状态只有单一 `{ri, ci}` | 无 range/row/column 选择模型 |

### 1.2 行列操作"够不着、看不清"

| # | 现象 | 代码证据 | 根因 |
|---|---|---|---|
| R1 | 单击列头**直接弹列菜单**（重命名/类型/排序…），既没有"选中整列"，也误触率高；菜单又长又高（最多 12 项） | th `onClick` → `setColMenuCi`（L1037）；菜单含 rename+5 类型+2 插入+3 排序+4 统计+删除 | 与 Notion 相反：Notion 单击列头=选中整列，菜单是 hover 出来的 ⋯ 或右键 |
| R2 | **没有"添加行"常驻入口**：原 spec §3.3.4 承诺"行尾「添加行」按钮（始终可见）"，实现只有"末行 Enter 自动加行"和行菜单 | 网格内无 add-row 按钮；角落 `+` 只加列（L993） | 新用户不知道 Enter 可加行 → 找不到入口 |
| R3 | 排序/筛选后**行号乱序跳变**：行号显示原始数据索引 `ri+1`（L1214），降序后显示 5,4,3…，筛选后出现 1,3,7 断号 | 行号列 `{ri + 1}`，ri 是数据行索引 | 视图与数据索引混用 |
| R4 | 排序/筛选态下**拖拽行**：拖的是隐藏行/乱序行，落点计算基于数据索引，视觉与结果脱节 | 行拖拽基于 `data-row`（原始索引） | 视图态下移动数据行语义混乱（Notion 在排序视图下不提供行拖拽） |
| R5 | 筛选态在**最后可见行**按 Enter 不会加行（判断基于数据总行数），新行"凭空消失"（被筛选隐藏） | Enter 分支 `nextRow >= table.rows.length`（L168），非可见行数 | 视图/数据两层索引混淆的连锁反应 |
| R6 | 行号列 40px 里塞了 3 个图标（拖拽手柄 + 序号 + ⋯ 菜单），挤且难以命中 | 行号 td 内 grip+number+menu 三件套（L1196-1213） | Notion 只有 hover 出现的 ⋮⋮ 手柄 + 单击行号选中整行 |
| R7 | 单击勾选/单选单元格**不选中该格**：勾选直接切换、单选直接弹选项，键盘连续操作无从谈起 | td onClick 对 checkbox/select 提前 return（L1373-1376） | 类型行为与选择行为耦合 |

### 1.3 浮层被裁剪、视觉不统一（"像半成品"）

| # | 现象 | 代码证据 | 根因 |
|---|---|---|---|
| P1 | 列菜单/单选选项/行菜单都是 `absolute` 挂在 th/td 内部（`left-0 top-full`），网格容器 `overflow-auto` → **横向滚到右列、或纵向滚到底部时菜单被容器裁掉**，部分菜单项不可见 | L1039 列菜单、L1320 选项弹层、L1227 行菜单均内嵌定位 | 浮层未 portal 到容器外（Notion 所有浮层渲染在页面级 overlay，永不裁剪，且贴边自动翻转） |
| P2 | 表格视觉仍套用工具壳语言：行高 ~28px（`py-1.5`）、选中态橙色 accent 描边、行 hover 橙色 tint | `cellClass`（L885）、`outline-[var(--accent-strong)]`（L1387） | 与 `doc-notion-polish` S5 裁决冲突：文档域 hover/选中应中性暖灰/蓝灰，橙色只给操作意图 |
| P3 | 单选列是"纯文本+小箭头"，不是彩色 chip；数字/日期列无类型约束（任意文本可入），日期列无 date 输入 | `default` 分支渲染（L1346-1360）；编辑统一 `<input>` | 原 spec 承诺的类型化呈现/校验未实现 |
| P4 | 顶部仍是"← 我的空间 + 图标按钮堆"的工具条形态，与文档页整改后的纸张语言不一致 | 标题栏（L896-905） | `doc-notion-polish` T1 的"内容优先"原则未延伸到表格 |

## 2. 参照模型：Notion 表格（数据库视图）交互行为表

Notion 数据库表格与简易表格的交互内核一致，逐项列为本版行为基准：

### 2.1 焦点与键盘（Notion 基准）

| 操作 | Notion 行为 | 本版决策 |
|---|---|---|
| 鼠标点单元格 | 选中该格，**焦点进入网格**，方向键/打字立即可用 | ✅ 采纳（K1/K2 修复的核心） |
| 直接输入字符 | 选中格处于编辑态，**整格内容被替换**（再按 ⌫ 恢复原值前不可撤销到逐字） | ✅ 保持现状（已一致） |
| Enter（编辑态） | 提交并**下移一格**；末行时自动新增行并进入新行 | ✅ 采纳（K4） |
| Shift+Enter（编辑态） | 单元格内换行（多行文本） | ✅ 采纳（K5，textarea） |
| Tab / Shift+Tab（编辑态） | 提交并右移/左移；**末列 Tab = 换到下一行首列**；末行末列 = 新增行 | ✅ 采纳（K3，与网格态统一） |
| Esc | 分级退出：编辑态→取消编辑回选中；选中态→清选区 | ✅ 采纳 |
| ⌘C / ⌘V | 复制/粘贴；粘贴支持外部表格（TSV/CSV 嗅探）**多行多列整体扩表**；选区粘贴到多格时按网格展开 | ✅ 采纳（K6） |
| ⌘A | 全选（全部单元格） | ✅ 采纳（K7） |
| Shift+方向键 / Shift+点击 | 扩展选区（矩形范围） | ✅ 采纳（K7） |
| Delete / Backspace | 清空选区全部单元格 | ✅ 采纳（扩展为多格） |
| ↑↓←→（选中态） | 移动选中格（边界钳制，不自动扩行） | ✅ 保持现状 |

### 2.2 行列选择与操作（Notion 基准）

| 操作 | Notion 行为 | 本版决策 |
|---|---|---|
| 单击行号 | 选中整行（再点扩展） | ✅ 采纳（R6 重构） |
| 单击列头 | 选中整列 | ✅ 采纳（R1 重构） |
| 列头 hover | 显示 ⋯ 下拉（列菜单：类型/排序/插入/删除…），单击列名不再弹菜单 | ✅ 采纳（R1） |
| 行号 hover | 显示 ⋮⋮ 拖拽手柄 + 行 ⋯ 菜单 | ✅ 采纳（R6） |
| 列宽拖拽 | 表头右缘拖拽；双击自适应 | ✅ 保持现状（命中区加宽） |
| 列拖拽重排 | 仅"未排序/未筛选"视图可拖（排序/筛选下拖拽语义混乱，Notion 直接不提供） | ✅ 采纳（R4：视图态禁用拖拽并提示） |
| 添加行 | 表格底部常驻 `＋` 行 | ✅ 采纳（R2） |
| 添加列 | 表头最右 `＋` 列 | ✅ 保持现状（已一致） |

### 2.3 浮层与反馈（Notion 基准）

| 操作 | Notion 行为 | 本版决策 |
|---|---|---|
| 列菜单/选项弹层/行菜单 | 渲染于页面级 overlay：**永不裁剪**、贴视口边缘自动翻转、点击外部关闭 | ✅ 采纳（P1，portal 化） |
| 行 hover | 整行暖灰底（`#f7f6f3` 系） | ✅ 采纳（P2） |
| 选中态 | 单元格整格底色高亮（蓝灰系），非描边 | ✅ 采纳（P2） |
| 状态反馈 | 底部状态栏极简短提示；排序/筛选/统计均为"视图态"不落盘 | ✅ 保持现状（补可见行数） |

## 3. 整改项清单（文件级）

### P0 — 交互正确性（"怪"的直接来源，优先级最高）

**T1 焦点闭环**（`TableEditor.tsx`）
- 新增 `gridRef`（table 元素）；`focusGrid()` = `gridRef.current?.focus({preventScroll:true})`。
- 挂载：单元格 `onClick` 选中后调用 `focusGrid()`；`commitEdit()` / 编辑 Tab 提交 / Esc 取消编辑后调用 `focusGrid()`；`moveSel()` 后调用。
- `<table>` 加可见焦点环（`focus-visible:outline` 2px 蓝灰虚线，对齐选区色），让用户知道"焦点在网格"。
- 验收：鼠标点任意格 → 方向键/Enter/打字全部可用；编辑提交后连续打字不再丢焦点；e2e 断言 `document.activeElement === table`。

**T2 编辑态键盘对齐 Notion**（`TableEditor.tsx`）
- 编辑控件按列类型切换：
  - 文本：`<textarea rows=1>`，Shift+Enter 插入 `\n`，Enter 提交并下移；行高随内容自适应（提交后单元格渲染保留换行，`truncate` 改为 `whitespace-pre-wrap` 两行截断）。
  - 数字：提交时校验，非数字（允许空）→ 标红边框 + 状态栏提示"仅支持数字"，不落盘不移动；非法值保留可改。
  - 日期：`<input type=date>`（值非法时回退文本编辑）。
  - 勾选/单选：单元格内联控件，见 T7。
- Tab/Shift+Tab：提交并右移/左移，**末列右移 = 下一行首列，末行末列 = 新增行并进入**（与网格态共用 `moveSel` + 加行逻辑）；Enter 提交并**下移**（末行 = 新增行）；Esc 取消。
- 验收：键盘矩阵（Notion 基准表 2.1 全项）有组件测试覆盖。

**T3 复制 / 粘贴**（`TableEditor.tsx` + `tableModel.ts` 新增 `parseClipboardText` / `serializeClipboard` 纯函数）
- ⌘C：选区（单格/多格矩形/整行/整列）→ 序列化 TSV（含 `\t`/`\n` 转义），写入 `navigator.clipboard`；单格复制时文本裸值。
- ⌘V：先嗅探剪贴板：含 `\t` 或 `\n` 且非纯文本段落 → 按 TSV 解析；粘贴到单格 = 从该格起**向右下展开**，超界自动扩列/扩行（上限 200 行 × 50 列，超限 toast 拒绝）；粘贴到多格选区且尺寸匹配 = 逐格填充；纯文本段落 = 单格整值。
- 单元格内编辑态 ⌘C/⌘V 走原生输入框行为（不拦截）。
- 验收：Excel/Notion 复制 3×4 表格粘入自动扩表；表内复制 2×2 粘到空区域；组件测试用 mock clipboard。

**T4 选区模型**（`TableEditor.tsx` + `tableModel.ts` 新增 `TableSelection` 类型与纯函数 `expandSelection`/`selectionCells`）
- 状态从 `{ri, ci}` 升级为 `{ anchor: CellPos, focus: CellPos, mode: 'cell' | 'row' | 'column' }`（矩形闭区间）。
- 交互：单击=锚定；Shift+点击=扩展；Shift+方向键=扩展；⌘A=全选（mode column 全列 × 全部行）；单击行号=整行、再 Shift+点击行号=连续多行；单击列头=整列、Shift+点击列头=连续多列；**整行/整列选区显示行号/列头同步高亮**。
- Delete/Backspace/直接输入：作用于全部选中格（输入字符=替换选区第一格，其余清空——与 Notion 一致）。
- 选区绘制：矩形内全部单元格整格底色（蓝灰系，见 T9），不再单格描边。
- 验收：选区矩阵组件测试（单格/多格/整行/整列/全选/Shift 扩展/越界钳制）。

**T5 行号与视图一致性**（`TableEditor.tsx`）
- 行号列显示**当前视图序号**（排序/筛选后仍 1..n 连续）；数据行号不对外暴露。
- 筛选态 Enter 在**最后可见行**追加新行：数据尾部插入；若新行被当前筛选隐藏 → 状态栏闪现提示"已添加行（可能被筛选隐藏）"；不再依赖数据总行数判断。
- 排序/筛选态：行拖拽手柄禁用（grip 置灰 + title 提示"排序/筛选下不可拖动"），行菜单保留。
- 验收：降序后行号 1..n 连续；筛选 3 行中末行 Enter 新增成功且有提示。

**T6 浮层 Portal 化**（`TableEditor.tsx`，新增 `TableMenuPortal` 小组件）
- 列菜单/单选选项弹层/行菜单统一渲染到 body 级浮层（`createPortal`）：定位 = 触发元素 `getBoundingClientRect()`，超出视口右/下边缘自动向左/向上翻转，最大高度限视口 60% 内部滚动。
- 打开期间：Esc 关闭、点击外部关闭、窗口 resize/滚动时重新定位（或直接关闭——取简单方案：滚动容器时关闭）。
- 验收：横向滚动到最右列、纵向滚动到底部，菜单全项可见；无 testid 回归破坏（testid 保留在浮层内）。

**T7 类型化单元格交互补齐**（`TableEditor.tsx`）
- 勾选列：单击 = 选中该格 + 空格/再次单击 = 切换（先选中后切换，键盘可达）。
- 单选列：单击 = 选中该格并展开选项（portal 化）；选项渲染为**彩色 chip**（色板按索引取，沿用 knowledge-table preview 的 `--chip0..5`）；当前值 chip 显示 + hover 出小箭头。
- 数字列：右对齐 + `tabular-nums`（已有）+ 校验（T2）。
- 日期列：`YYYY-MM-DD` + date 控件（T2）。
- 验收：五类型各自交互链路组件测试更新。

### P1 — 呈现与入口（"像不像"）

**T8 添加行 / 添加列对称**（`TableEditor.tsx`）
- 表格底部常驻「添加行」行：左侧 `＋` 图标 + 灰字"添加行"（数据尾部追加，选中新行首格并聚焦）；表头最右保留「添加列」`＋`（现状）。
- 空表（1 行）时首行即显示引导 hint（沿用"双击开始输入"），底部添加行提示常驻。
- 验收：新增行按钮可见性不依赖滚动位置；点击后直接可输入。

**T9 视觉 Notion 化**（`TableEditor.tsx` + `knowledge-doc-typography.css` 或表格局部 CSS）
- 行高 34px（`py-2` 级）；表头行高 32px、底边 1px 强边框区分；表头文字 12px/600 灰黑。
- 行 hover 整行暖灰（亮 `#f7f6f3` / 暗 `#2a2a2a`，复用 doc-notion-polish 的 `--doc-row`）；选中格整格底色蓝灰（亮 `rgba(45,110,220,.10)` / 暗 `rgba(93,160,255,.16)`），选中行列头/行号同步淡色。
- 列头 hover：整格暖灰 + 右侧淡入 ⋯（列菜单入口，单击列头=选中整列，T4）；去掉 grip 图标（拖拽改由 ⋯ 菜单"移动列"或按住列头空白处拖，见 T10 取舍——**本版取：按住列头文字区即可拖拽重排，hover 显示 ⋯ 菜单**）。
- 行号列宽 44px；行号 hover 显示 ⋮⋮ 手柄（拖拽）+ ⋯（行菜单），去掉常驻三图标（R6）。
- 工具栏精简：移除"← 我的空间"按钮（返回改为标题上方面包屑小字路径，对齐 doc-notion-polish T1）；撤销/重做保留；冻结首行并入 ⋯ 菜单（或保留为低饱和图标）；排序/筛选/统计/导出图标保留但 hover 中性灰。
- 底部状态栏：左「可见行/总行 · 列数」（筛选时 `5 / 12 行`），右保存状态（saved 静默、saving/error 显示，沿用现逻辑）。
- 验收：对照 preview 截图逐项比对；无橙色 tint 残留在表格 hover/选中态。

**T10 列/行菜单结构收敛**（`TableEditor.tsx`）
- 列菜单（hover ⋯ / 右键）：分组为 ① 类型（5 项，子菜单或平铺 5 行）② 排序（升/降/清除）③ 插入左/右、删除 ④ 统计（Σ 开时显示）；重命名改为**双击列名内联编辑**（Notion 交互），从菜单移除。
- 行菜单：插入上方/下方、复制行、删除行（现状保留，样式随 T9）。
- 验收：菜单最长 9 项（vs 现状 12+）；双击列名直接改名。

## 4. 关键交互时序

**F1 鼠标点选 → 键盘连续编辑（当前断、改后通）**
```
当前：点击单元格 → setSel → focus 留在 body → 方向键滚动页面 ✗
改后：点击单元格 → setSel + focusGrid() → 方向键/Enter/打字全可用 ✓
  → 打字进入编辑 → Enter 提交并下移 → focusGrid() → 继续打字 ✓
```

**F2 外部粘贴扩表**
```
⌘V（剪贴板含 \t/\n）
  → 嗅探 TSV → 从选中格向右下展开
  → 超界自动扩列/扩行（上限 200×50）→ 一步历史 → 800ms 防抖落盘
```

**F3 排序视图下添加行**
```
排序/筛选激活 → 末可见行 Enter
  → 数据尾部追加新行 → 行号视图重排 → 新行被隐藏则状态栏提示
  → 清除筛选后新行出现（数据不丢）
```

**F4 列菜单浮层**
```
列头 hover → ⋯ 淡入 → 点击 → portal 浮层（body 级）
  → 视口右缘自动左翻 → Esc/外部点击关闭
```

## 5. 验收标准（Done 定义）

1. **焦点闭环**：鼠标点选后键盘 100% 可用（T1）；编辑提交/Esc 后焦点回网格。
2. **键盘矩阵**：Notion 基准表 §2.1 全部通过组件测试（Tab 末列换行、Enter 提交下移+末行加行、Shift+Enter 换行、Esc 分级）。
3. **复制粘贴**：外部 TSV 扩表粘贴、表内多格复制、单格纯文本粘贴，三链路有测试。
4. **选区**：⌘A / Shift+扩展 / 整行 / 整列 / 多行多列选区绘制正确，Delete 批量清空。
5. **视图一致性**：排序/筛选后行号连续；筛选末行 Enter 加行有提示；排序/筛选态行拖拽禁用。
6. **浮层**：网格滚到任意位置，列菜单/选项弹层/行菜单全项可见、不裁剪、贴边翻转。
7. **入口**：底部「添加行」常驻可见，点击即可输入。
8. **视觉**：行高 34px、行 hover 暖灰、选中蓝灰整格底、列头 hover ⋯；表格内无橙色 tint 残留。
9. 回归门禁：`yarn tsc`、`yarn test` 全绿（TableEditor 既有测试按新交互更新，不删语义）。

## 6. 非目标（本版明确不做）

- 功能范围扩张：不多视图、不表间关联、不公式引擎（沿用 knowledge-table P0/P1 边界）；
- 多选后批量编辑弹层、批量类型转换（P2 候选）；
- 单元格内富文本/块编辑（文本列多行已覆盖）；
- 行/列隐藏、列固定（Notion 高级特性，P2 候选）；
- 拖拽调整表格在文档中的位置（表格是独立节点，非文档内嵌块）。

## 7. 风险与对策

| 风险 | 等级 | 对策 |
|---|---|---|
| 选区模型重构触碰既有测试面大（~30 用例） | 中 | 选区纯函数先测（`expandSelection`/`selectionCells`/`parseClipboardText`），组件测试增量替换；P0 分 T1→T7 逐个 PR 提交 |
| Portal 浮层与 Tauri webview 兼容（`createPortal` 到 body 在滚动容器内定位漂移） | 中 | 打开时快照触发元素 rect + 滚动监听关闭；e2e 覆盖横向滚动后菜单可见性 |
| 粘贴嗅探误判（普通多行文本被当 TSV） | 低 | 规则：含 `\t` 才视为表格；仅 `\n` 且无 `\t` 的视为单格多行文本 |
| 文本列换行（textarea）改变行高影响大表性能 | 低 | 行高自适应仅在编辑态；提交后单元格固定两行截断（`line-clamp-2`），不逐格测高 |
| 视觉改动与既有 e2e 选择器冲突 | 低 | 保留全部 `data-testid`（含新增 `table-add-row`、`table-col-arrow`、`table-selection`）；行号 testid 语义不变 |

### 8.1 现状审计

### 8.2 整改项（文件级，P0 随 T1–T10 同批）

**TB1 工具栏三段式布局**（`TableEditor.tsx` 标题栏区）
- 结构：面包屑小字行（移除"← 我的空间"返回按钮）→ 标题行（32px/650，hover 出 ⋯ 页面菜单）→ 工具栏行（36px）。
- 工具栏分组：`[撤销 重做] │ [筛选 统计 导出] │ (spacer) [视图状态 chips] [⋯ 菜单]`。
- 行数/列数 pill 从工具栏移除（O8）；底部状态栏保留。
- 验收：窄窗口下标题不再被挤压；返回行为 = 面包屑点击；`table-editor-back` testid 移除或改挂面包屑。

**TB2 关键操作文字化**（O1/V1/V5）
- 筛选、统计、导出升级为**文字按钮**（14px 图标 + 12px 文案，`h-7` 28px，`px-2.5` 圆角 6px，默认文字 `text-ink-secondary`、hover 暖灰底）；
- 撤销/重做保留图标按钮但放大到 28px 命中区、图标 14px、禁用态加 tooltip；
- 冻结首行移入 ⋯ 菜单（O3）。
- 验收：无鼠标 hover 时工具栏各按钮职责可读；e2e 文本断言（`table-filter` 内含"筛选"文字）。

**TB3 激活态实底化**（O2/V3/V4）
- 激活（aria-pressed=true）：`bg-btn-primary text-on-btn-primary` 实底白字（与徽标同色系）；
- 视图状态（排序/筛选生效）统一为右侧 chip 组：`bg-tbl-row-hover` 浅暖灰底 + 12px 文字 + × 清除，样式与列菜单状态一致；筛选 chip 文字带条件数「筛选 · 2」。
- 验收：激活按钮与 hover 态在任意主题下可区分（对比度 ≥ 3:1）；截图比对。

**TB4 筛选 Popover 化**（O5/V6，复用 T6 portal 机制）
- Filter 按钮点击 → portal 浮层（body 级、贴边翻转），内容：条件列表（列选择器 + 操作符 + 值，行式布局，非原生平铺）+ 底部「添加条件」「清除全部」+ 右上 ×；
- Esc / 点击外部 / 滚动关闭；条件数显示在按钮与 chip 上；
- 移除嵌入式 `table-filter-panel`（testid 迁移到浮层内）。
- 验收：网格横向滚动后浮层不裁剪；`table-filter-panel` 不再出现在 DOM 流中。

**TB5 统计入口闭环**（O6）
- 列菜单"统计"区块**不再依赖 statsOn**（常驻显示）；Σ 激活时统计行 hover 单元格显示"切换模式"快捷操作；
- 工具栏 Σ 保持总开关（实底激活态）。
- 验收：statsOn=false 时列菜单仍可配置逐列模式（配置后自动开启 Σ）。

**TB6 视图操作不入撤销栈**（O12）
- 排序/筛选变更不再 `pushHistoryStep`；撤销/重做仅覆盖内容与结构操作；
- undo/redo 不再重置选区（`applySnapshot` 保留当前选区，越界钳制即可）。
- 验收：排序后 ⌘Z 撤销的是上一次内容编辑而非排序；选区不跳变。

**TB7 保存状态静默化**（O7）
- saved：状态栏右侧仅极淡"✓ 已保存"或完全静默（默认静默，>800ms 才显示 saving；error 必显+重试）；
- 对齐 doc-notion-polish T1：文档页与表格页保存反馈位置/时序一致。
- 验收：连续编辑 10s 无任何"已保存"常驻提示；error 态可见且可重试。

**TB8 导出语义说明**（O10）
- 筛选激活时导出按钮 tooltip 追加「将导出全部数据（不含筛选）」；点击后 toast 同文案。
- 验收：筛选态导出 toast 含"全量"字样；导出文件为全量数据（测试断言）。
