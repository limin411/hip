本原型覆盖的交互（全部可操作）
  • 块编辑：Enter 拆分 · Backspace 合并/降级 · ↑↓ 跨块移动 · 点击空白追加段落
  • 斜杠菜单：/ 唤起，输入过滤，↑↓ 选择，Enter 应用，Esc 关闭
  • Markdown 快捷输入：# 标题 · - 列表 · 1. 编号 · [ ] 待办 · > 引用 · !> 提示框 · ``` 代码 · --- 分割线
  • 行手柄（hover 左侧）：≡ 拖拽排序（虚线指示落点）· ＋ 下方插入 · ⋯ 上移/下移/复制/删除/转标题
  • 待办勾选（点击复选框）、表格单元格编辑、代码块 Tab 缩进、⌘B/⌘I 加粗斜体
  • 自动保存指示（状态栏圆点 + 时间）；「重置示例文档」恢复种子内容
  • 无源码模式：全程无「源码 / Markdown 模式」切换入口（对齐 Notion / 飞书 / 语雀）
