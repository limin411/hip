方案 B：16px 原生像素网格 · 1.5px 硬终端 · active 填充态

与方案 A（24px 源图 · 1.75px 圆端 · 双色）完全不同的路线：放弃"大图缩 16"，直接在 16×16 像素网格上设计； 描边 1.5px、方形终端、1px 圆角 —— 与 hip 的"直角优先 Sharp over Round"设计语言完全一致； 菜单 active 态由底色升级为图标实底填充，层级不再靠一档灰阶区分。

三、规范细节

关键差异点：像素对齐、硬终端、填充态、12px 降采样、明暗对比。

3.1 16px 像素网格 + 参考形

  • 网格 16×16，绘制即最终尺寸，无 24 源图
  • 内容区 14×14（1px 光学边距）
  • 垂直/水平描边对齐整像素；45° 线对齐 0.5 步进
  • 参考形（Primer 法）：圆 r5.5、方 11×11、对角线 12 —— 图标按此光学体积布线（紫色虚线为参考圆）
  • 外角圆角 1px；填充细节 0.25px

3.2 描边（square 终端 / round join）

1.25 · 过细
1.5 · 选定
1.75 · 过重
1.5px 在 16px 原生网格上 = 1 整像素 + 两侧各 0.25 亚像素，清晰无糊。 方形终端（Material/Geist 法）与 DESIGN.md「直角优先」一致；join 用 round 防尖角挂刺。

3.3 尺寸档（16 原生 + 降采样/放大）

12px = 16 核心集直接降采样（标签/元数据，Atlassian 法）；16px = 菜单标准；24px = 同图形放大（空状态）。 不设 20px 工具栏档与 40–64px 品牌位（品牌位由吉祥物承担）。

3.4 active 填充态（B 的核心差异）

  • active = 图标实底填充 + 底色，缺口（气泡点/勾/齿轮孔）用底色掏空
  • 填充变体命名 hip-sessions-filled（Siemens -filled 惯例）
  • hover 只变底色；focus 2px 方形 ring；禁用 opacity-40

3.5 明暗对比（Linear 法）+ 分类法（Atlassian 法）

  • 亮色模式图标比文字深一档、暗色模式浅一档；永远 currentColor，无图标专属色
  • 单用途：按语义命名（hip-sessions / hip-tasks），全库唯一用法
  • 多用途：按图形命名（hip-chevron-right / hip-search），允许复用
  • 新增图标先查分类法，禁止同一图形两种语义

3.6 工具链（借鉴 Atlassian 迁移工程）

  • hip-icon-migration ESLint 规则：内置映射表 + --fix 自动改写，预期自动修复率 ≈75%（Atlassian 实测值）
  • Icon Facade：<MessageSquare/> 运行时渲染为 hip-sessions，零调用点改动即可全 app 预览
  • SVG 扫描审计：脚本扫全库图标调用点 → 截图 → 人工复核文档
  • Feature flag + legacy 兜底 prop，随时切回
