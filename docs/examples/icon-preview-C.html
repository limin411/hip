方案 C：2px 醒目圆端 · 选中即品牌橙 · 右下角状态徽标

与 A（细线双色）、B（极简像素）不同：C 用 2px 粗描边 + 3px 圆角 做出"温暖可靠"的辨识度（Raycast 法）； active = 图标实底填充品牌橙（SF Symbols「fill = 选中」法）—— 选中即品牌时刻，Flat Butt 吉祥物的暖橙正式进入菜单； 并引入 右下角状态徽标（Fluent modifier 法）+ slash / enclosed 变体（SF Symbols 法）。

粗描边醒目 · 2px 恒定圆端 选中即品牌橙 · active = accent 实底 状态徽标 · 右下角 4px 圆 三变体 · -filled / -slash / -enclosed 温暖友好 · 与吉祥物同频
Raycast 2022 · 图标体系重建

与 hip 同类的"温暖实用型"工具。核心：outline + 加粗描边（bolder stroke）做可辨识度；统一描边宽与圆角规则；品牌红只做标点不铺满。

Apple SF Symbols fill = 选中

四种渲染模式 + 设计变体（fill / slash / enclosed）。规则明确：fill 变体用于选择 —— iOS tab bar 用 fill + accent 色表达选中。

Microsoft Fluent 2 modifier + 多尺寸

Regular / Filled 双主题（Filled = 选中高亮）；modifier 修饰符统一放图标右下角；12–48px 各档逐档重绘而非缩放。

Vercel / Apple HIG 状态入图标

Vercel 把部署状态做进 tab 图标（构建/就绪/失败）。Apple HIG：图标应表达产品个性 —— hip 的个性就是暖橙吉祥物。

三、规范细节

关键差异点：品牌橙 active、状态徽标、三变体体系。

3.1 active = 品牌橙实底（选中即品牌时刻）

线条·常态
会话
active
选中态（品牌橙）
  • active = 图标实底 --accent（亮 #c2410c / 暗 #ffb300）+ --on-accent 掏空细节
  • 与 DESIGN.md「暖橙唯一强调色」一致：不用左条，图标本身就是强调

3.2 状态徽标（右下角 4px · Fluent modifier 法）

徽标带 1px 底色描边环（任何底色可辨）；颜色沿用状态 token（success/warning/danger/tertiary）。 适用：终端=连接、自动化=排队、会话=新消息。

3.3 变体体系（SF Symbols 法）

  • -filled：active 选中态（品牌橙实底）
  • -slash：功能未启用 / 禁用 —— 例：语音未配置（见总表「语音」右侧）
  • -enclosed：20px 圆角底板，托盘 / 工具栏 / 空状态 —— 例：右侧齿轮 enclosed 图块

3.4 描边（round 终端 · 醒目）

1.75 · A 案
2.0 · 选定
2.25 · 过粗
2px 在 16px 菜单下有效 1.33px，比 A（1.17px）醒目 14%；14px 右键档 1.17px 仍可辨。 终端 round + join round；形状外角 3px（比 A 的 2px 更圆润，呼应吉祥物曲线）。

3.5 尺寸档

16px 菜单 / 20px 重绘档（工具栏/托盘，Fluent 多尺寸思想：关键档重绘不缩放）/ 24px 空状态 / 40–64px 品牌位（enclosed + 吉祥物）。
