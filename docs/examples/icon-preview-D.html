方案 D：分层单色（Hierarchical）+ 模块几何原语

与 A（双色实底点缀）、B（中性填充 active）、C（整图标品牌橙 active）都不同： D 把每枚图标拆成 primary / secondary 两层，常态用 100% / 40% 透明度 做深度（SF Symbols hierarchical）； active 时 仅主层变品牌橙，次层保持中性 —— 选中「点亮结构」而非整图标染色。 构造上强制 几何原语白名单（Bauhaus / Block），保证整套像同一只手画的。

几何规范 + 光学补偿；Micro 档简化细节。D 的 mono 模式 = 小尺寸时压掉次层。

三、规范细节

3.1 图层：常态分层 vs active 主层橙

  • primary 100% · secondary 40% · 同色 currentColor
  • active：primary = --accent，secondary 仍中性 40%
  • 区别于 C：C 是整图标橙实底；D 是「点亮结构」

3.2 模块几何原语（白名单）

新图标只能用：圆 / 圆角方 rx2 / 水平垂直 45° 线 / 90·180·270° 弧 / 等腰三角。禁止自由贝塞尔与透视体。

3.3 网格 20px · 描边 1.6 / 1.4

  • 设计网格 20×20；菜单 16 缩放；工具栏 20 1:1
  • primary 描边 1.6px · secondary 1.4px（次层略细）
  • 右键 14px 强制 layers=mono（压掉次层防糊）
