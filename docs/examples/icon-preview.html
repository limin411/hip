主题 尺寸 16px 描边 双色

菜单图标全面升级：从 lucide 通用图库 → hip 自绘图标集

现状：6 个主侧栏导航、3 个 footer、11 个设置导航、23 个右键菜单图标全部取自 lucide-react， 无品牌语言、描边尺寸不统一、状态无表达。本方案定义 hip-icon 自绘图标集（24×24 网格、1.75px 描边、 2px 圆角、暖橙双色层），并给出全量 lucide→hip 迁移映射与分阶段计划。

四、规范细节

与 DESIGN.md / tokens.css 对齐；数值为最终实施值。

4.1 网格与安全区

  • 设计网格 24×24，与 lucide 同源，可直接替换
  • 主体 ≤ 22×22 安全区（橙色虚线框），留 1px 光学余量
  • 关键元素落在 18px 光学圈 内，重心统一
  • 坐标取 0.5 步进（4.5 / 12.5），16px 渲染时不糊线
  • 对称图标按 45° / 90° 轴对称，禁止手抖曲线

4.2 描边（端点 round / join round）

1.5 · 过细
1.75 · 选定
2.0 · lucide
1.75 比 lucide 默认 2 细 12.5%：菜单 16px 下更工具化、不拥塞；比 1.5 更稳，hover 态不闪。 lucide 混用 2 与个别 1.75 的现状一并归一。

4.3 尺寸档（菜单标准档 = 16px）

14px 右键菜单 / 16px 菜单标准 / 20px 工具栏 / 24px 空状态 / 40–64px 品牌位（双色）。 禁止 12/13/15/17/18 等散点尺寸出现在菜单。

4.4 双色规则（Duotone）

  • 双色层 --icon-duo：亮 #c2410c / 暗 #ffb300，面积 ≤ 25%
  • 仅品牌位：空状态大图、欢迎页、active 高亮（默认关）
  • 菜单常态、右键菜单、14px 以下一律单色 currentColor

4.5 交互状态（菜单行）

  • 常态：单色 currentColor，随行文字色
  • hover：底色 --state-hover，图标不变形不变色
  • active：底色 --state-active；可选双色层（默认关）
  • focus：2px accent 方形 ring（沿用全局）；禁用：opacity-40
  • 过渡：background-color/color 100ms，无位移无缩放

4.6 渲染层（P1 实施）

  • HipIcon name size duo title 组件 + hip-icons.ts 路径数据
  • 默认 aria-hidden，菜单行文本承担无障碍标签
  • 与 lucide 并存期：逐模块替换，任何阶段可 revert
  • tree-shake 友好，体积远小于 lucide 全量
