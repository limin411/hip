Cursor Agent 风格 · 按钮升级提案 ✓ implemented 2026-07-11

参考 Cursor Agent Desktop / IDE 侧栏的交互气质： 暗色优先、单色层级、填充表达主次、少描边、更密更软。 已落地 buttonVariants + Composer 圆钮 + Cancel ghost + SegmentedControl。 对照现状页见 index.html。

01 · Hierarchy

用填充，不用描边抢戏

Cursor 主操作是「反色实心」（亮色近黑底、暗色近白底）。次级是轻灰底或纯 ghost。现在 hip 的 primary 深描边 + 白底，在 IDE 场景里偏「表单按钮」，不够 Agent 工具感。

02 · Density

更矮、更软、字重更轻

md 建议 32px（现 36）、圆角 8、字号 ~12.5、字重 500。Chrome 里按钮应像工具栏控件，不是营销 CTA。

03 · Quiet chrome

默认安静，hover 才出现

大量操作用 ghost；outline 降级为少数场景。发送键做成圆形实心图标，而不是大块 primary 文字钮。

6 · 映射到 hip 实现

Save / Apply / Add primary 深描边 primary → solid inverse（黑/白填充）
Cancel / 次要 outline 或 secondary 对话框 Cancel → ghost；并列次操作 → secondary 软底
Composer Send primary 文字钮 圆形 icon send（可仍走 primary 色 token）

Login Email elevated primary 与全局 solid primary 统一
Delete confirm danger 实心 保留；列表行内删除 → dangerSoft
品牌绿 已移出 CTA 继续：仅选中条 / 状态点 / 可选 focus 点缀，绝不作按钮油漆
我的推荐优先级： ① 改 buttonVariants.primary 为 solid inverse； ② size 略收（md=32）； ③ Composer 发送改圆 icon； ④ 对话框 Cancel 默认 ghost； ⑤ 新增 Segmented + 可选 dangerSoft。

这比「继续描边 elevated」更接近 Cursor Agent Desktop，同时仍守住 hip 的克制与无绿底 CTA。
