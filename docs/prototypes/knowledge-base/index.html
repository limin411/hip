权限模型 v2 决策记录

最后编辑 · 今天 14:32 · Markdown · 本地存储

结论： 采用「会话级权限模式 + 工具白名单」双层模型， 与现有 PermissionModePicker 对齐，不引入全局 RBAC。

背景

v1 仅有粗粒度 approve / auto。在 Code 表面接入终端与写文件后， 用户需要更细的默认策略，同时保持 Chat 的轻量体验。 相关文档见目录中的「Agent 默认权限」与「Checkpoint 与 Timeline 设计」。

方案对比

  • A. 全局 RBAC — 过重，桌面单用户场景收益低
  • B. 仅会话权限模式 — 简单，但无法限制高危工具
  • C. 会话模式 + 工具白名单（采用） — 与现网组件兼容

落地要点

1）新建会话继承上次模式；2）危险工具始终二次确认； 3）文档按文件夹组织，通过目录与搜索发现。竞品笔记见 Cursor 上下文。
