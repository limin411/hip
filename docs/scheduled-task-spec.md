# SPEC: 定时任务集成到对话输入框

## 1. 背景与目标

### 当前状态
- 自动化功能通过独立的 `AutomationsPage` 页面访问
- 用户需要离开当前对话上下文才能创建/管理自动化

### 目标
- 在对话输入框底部工具栏添加"定时任务"按钮
- 点击按钮弹出简洁的时间设置窗口
- 对话输入框上方显示已设置的定时任务信息（类似异步shell窗口）
- 删除独立的自动化页面，简化导航

## 2. 设计方案

### 2.1 入口位置

在 Composer 底部工具栏的右侧添加"定时任务"按钮：

```
┌─────────────────────────────────────────────────────────────────┐
│  [Textarea 输入区域...]                                          │
├─────────────────────────────────────────────────────────────────┤
│  [Agent] [Model] [Effort] [附件]    [TokenUsage] [定时任务] [发送] │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 定时任务按钮

- **位置**: 底部工具栏右侧，发送按钮左侧
- **样式**: 使用 ComposerChip 组件样式（h-7, rounded-sm, text-meta, font-medium）
- **图标**: 使用 `Clock` 图标（lucide-react）
- **状态**:
  - 默认状态：text-ink-tertiary，hover:bg-state-hover
  - 已设置定时任务：active 状态（bg-state-active, text-ink），显示时间标签
  - 悬停：text-ink-secondary

### 2.3 时间设置弹窗

点击"定时任务"按钮后，弹出简洁的时间设置窗口（使用 Popover 组件）：

```
┌─────────────────────────────────────┐
│  定时任务设置                    [×] │
├─────────────────────────────────────┤
│  执行频率                           │
│  ┌─────────────────────────────────┐│
│  │ 每天  ▼                         ││
│  └─────────────────────────────────┘│
│                                     │
│  执行时间                           │
│  ┌─────────────────────────────────┐│
│  │ 09:00                           ││
│  └─────────────────────────────────┘│
│                                     │
│  提示：当前对话内容将作为任务执行    │
│                                     │
│  ┌─────────┐  ┌─────────────────┐  │
│  │  取消   │  │  设置定时任务   │  │
│  └─────────┘  └─────────────────┘  │
└─────────────────────────────────────┘
```

### 2.4 定时任务状态栏

当对话存在定时任务时，在输入框上方显示状态栏：

```
┌─────────────────────────────────────────────────────────────────┐
│ ⏰ 定时任务：每天 09:00 执行                              [编辑] [×] │
│    下次执行：明天 09:00                                          │
└─────────────────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────────────────┐
│  [输入框区域...]                                                 │
│                                                                  │
│  [Agent] [Model] [附件]    [定时任务] [发送]                     │
└─────────────────────────────────────────────────────────────────┘
```

状态栏特点：
- 位置：输入框上方
- 样式：与现有 diff annotations 风格一致（rounded-md border border-border bg-surface-muted px-2.5 py-1.5）
- 内容：显示任务频率、时间、下次执行时间
- 关闭按钮：手动点击可关闭（仅隐藏显示，不删除任务）
