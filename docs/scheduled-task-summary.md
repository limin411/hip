# 定时任务集成到对话输入框 - 方案总结

## 🎯 核心目标

将定时任务能力从独立的自动化页面集成到对话输入框，实现：
- **零上下文切换** - 在对话中直接设置定时任务
- **一键操作** - 点击按钮即可设置
- **清晰可见** - 状态栏实时显示任务信息
- **界面简化** - 移除独立自动化页面

## 📊 设计方案

### 1. 入口位置

在 Composer 底部工具栏的右侧添加"定时任务"按钮：

```
┌─────────────────────────────────────────────────────────────────┐
│  [Textarea 输入区域...]                                          │
├─────────────────────────────────────────────────────────────────┤
│  [Agent] [Model] [附件]    [TokenUsage] [定时任务] [发送]        │
└─────────────────────────────────────────────────────────────────┘
```

### 2. 定时任务按钮

- **位置**: 底部工具栏右侧，发送按钮左侧
- **样式**: 使用 ComposerChip 组件样式（h-7, rounded-sm, text-meta, font-medium）
- **图标**: 使用 `Clock` 图标（lucide-react）
- **状态**:
  - 默认状态：text-ink-tertiary，hover:bg-state-hover
  - 已设置定时任务：active 状态（bg-state-active, text-ink），显示时间标签
  - 悬停：text-ink-secondary

### 3. 时间设置弹窗

点击按钮后弹出简洁的设置窗口（使用 Popover 组件）：

```
┌─────────────────────────────────────┐
│  定时任务设置                    [×] │
├─────────────────────────────────────┤
│  执行频率                           │
│  ┌─────────────────────────────────┐│
│  │ 每天  ▼                         ││
│  └─────────────────────────────────┘│
│                                     │
│  执行时间                           │
│  ┌─────────────────────────────────┐│
│  │ 09:00                           ││
│  └─────────────────────────────────┘│
│                                     │
│  提示：当前对话内容将作为任务执行    │
│                                     │
│  ┌─────────┐  ┌─────────────────┐  │
│  │  取消   │  │  设置定时任务   │  │
│  └─────────┘  └─────────────────┘  │
└─────────────────────────────────────┘
```

### 4. 定时任务状态栏

当对话存在定时任务时，在输入框上方显示状态栏：

```
┌─────────────────────────────────────────────────────────────────┐
│ ⏰ 定时任务：每天 09:00 执行                              [编辑] [×] │
│    下次执行：明天 09:00                                          │
└─────────────────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────────────────┐
│  [输入框区域...]                                                 │
│                                                                  │
│  [Agent] [Model]    [定时任务 09:00] [发送]                     │
└─────────────────────────────────────────────────────────────────┘
```

状态栏特点：
- 位置：输入框上方
- 样式：与现有 diff annotations 风格一致（rounded-md border border-border bg-surface-muted px-2.5 py-1.5）
- 内容：显示任务频率、时间、下次执行时间
- 操作：编辑按钮、关闭按钮
- 关闭按钮仅隐藏显示，不删除任务

### 5. 删除自动化页面

- 移除侧边栏中的"自动化"导航项
- 移除 `AutomationsPage` 及相关组件
- 保留定时任务的核心功能（存储、调度）
