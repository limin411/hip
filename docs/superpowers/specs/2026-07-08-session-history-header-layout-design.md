# 历史会话页面头部布局优化设计

## 目标

优化 `历史会话`（SessionHistory）页面的头部布局：

1. 将分页组件移到右上角，与 `全部/办公/编码` 标签位于同一水平线。
2. 美化 `全部/办公/编码` 标签，调整间距，避免拥挤。

## 决策记录

- **分页可见性**：仅当 `totalPages > 1` 时显示分页；单页或空状态时完全隐藏，保持顶部简洁。
- **页码信息位置**：与分页组件一起放在右上角同一行（位于分页右侧或左侧，与分页紧邻）。
- **标签风格**：保留现有下划线 Tabs 风格（与整体 UI 一致），通过增大 `gap`、触发器水平内边距和统一高度来改善拥挤感。

## 布局

当前结构（简化）：

```
[标题]                        [清空全部]
[搜索框]
[全部] [办公] [编码]
[会话列表]
[分页]                第 N 页 / 共 M 页
```

优化后结构：

```
[标题]                        [清空全部]
[搜索框]
[全部] [办公] [编码]          [< 1 2 3 >] 第 N 页 / 共 M 页
[会话列表]
```

实现方式：在搜索框下方新增一行 flex 容器：

- 左侧：`Tabs`（`TabsList` 包含三个 `TabsTrigger`）。
- 右侧：`Pagination` + 页码信息文本，仅在 `totalPages > 1` 时渲染。

## 样式细节

- **TabsList**：增大 `gap`（例如 `gap-2` 或 `gap-3`），避免标签紧贴。
- **TabsTrigger**：
  - 增加水平内边距（例如 `px-3` 或 `px-4`）。
  - 固定高度 `h-9`，与右侧 `Pagination` 的按钮高度一致，保证同一行视觉对齐。
  - 保持现有下划线激活态、hover 态和文字颜色不变。
- **右侧区域**：`flex items-center gap-3`，分页与页码信息紧邻；整体 `items-center` 保证与左侧 Tabs 水平居中对齐。
- **响应式**：优先保持同一行；若窗口过窄，可允许右侧分页通过 `flex-wrap` 换行，但不改变组件内部行为。

## 行为

- 切换标签或搜索时，页码重置为 1（现有逻辑保持不变）。
- 分页交互（上一页/下一页/页码点击）保持不变。
- 空状态不渲染分页和页码信息。
- 单页（`totalPages === 1`）不渲染分页和页码信息。

## 无障碍

- 分页组件本身已具备 `role="navigation"` 和 `aria-label="Pagination"`。
- 页码信息文本使用普通 `span`，仅作视觉提示，不添加额外交互角色。
- Tabs 继续使用 Radix UI Tabs，保持键盘导航和 `aria-selected` 状态。

## 涉及文件

- `src/components/history/SessionHistory.tsx`：调整头部布局与 Tabs 样式。
- `src/components/history/SessionHistory.test.tsx`：现有测试用例不需要修改；标签文本和分页数字选择器保持不变。

## 不改动范围

- 不修改 `Pagination`、`Tabs`、`TabsList`、`TabsTrigger` 组件的默认实现，避免影响其他页面。
- 不改变清空全部按钮的位置和样式。
- 不改变会话列表项的样式和交互。
